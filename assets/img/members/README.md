# Fotos dos membros

Coloque aqui um arquivo `.jpg` por membro, nomeado com o `slug` usado em
`_data/members.yml`:

```
landulfo.jpg
moreira.jpg
alves.jpg
oliveira.jpg
depaula.jpg
dejesus.jpg
silva.jpg
mota.jpg
```

As imagens são exibidas em recorte circular de 5rem — o ideal é enviá-las
quadradas, com pelo menos 400×400 px, e com o rosto centralizado.

Quem não tiver foto aparece automaticamente com as iniciais sobre um fundo
suave; nada quebra por ausência do arquivo.
